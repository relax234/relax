# Сборка компактного OptiCore.exe (~20-30 МБ)

Если вы хотите получить компактный и быстрый `.exe` файл, который весит всего около 20–30 МБ и открывает приложение на вашем ПК и у друга без громоздких библиотек:

### Быстрый способ на Windows:
1. Скачайте проект к себе на компьютер с Windows.
2. Кликните правой кнопкой мыши по файлу **`build-light-exe.ps1`** и выберите **«Выполнить с помощью PowerShell»** (либо откройте PowerShell в папке проекта и введите `.\build-light-exe.ps1`).
3. Встроенный в Windows компилятор `.NET` за секунду создаст готовый **`OptiCore.exe`** в папке **`release/`**.
4. Файл весит всего несколько мегабайт, моментально запускается, сохраняет весь интерфейс и все возможности оптимизации в реальном времени!
