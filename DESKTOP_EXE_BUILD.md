# Пошаговая инструкция: как без ошибок опубликовать релиз и получить .exe на GitHub

Ошибка `tag name can't be blank` возникает на сайте GitHub, когда вы нажимаете кнопку публикации релиза, но забыли указать или выбрать **тег (Tag)**. 

Вот точный алгоритм, как сделать всё правильно за 1 минуту без единой ошибки:

### Шаг 1: Загрузить файлы на GitHub
Убедитесь, что в ваш репозиторий на GitHub загружены все файлы проекта (включая папки `.github`, `electron` и файл `package.json`).

### Шаг 2: Создать релиз на GitHub
1. Перейдите в ваш репозиторий на GitHub.
2. В правой колонке нажмите на **Releases** (или перейдите по адресу `https://github.com/ВАШ_АККАУНТ/ВАШ_РЕПОЗИТОРИЙ/releases/new`).
3. **Самое главное (исправление ошибки с тегом):**
   - Нажмите на выпадающее меню **Choose a tag** (Выбрать тег).
   - Введите прямо туда новый тег: **`v1.2.0`** (обязательно с буквой `v` в начале).
   - Под полем появится подсказка: **`+ Create new tag: v1.2.0 on publish`** — нажмите на неё!
4. В поле **Release title** напишите название, например: `OptiCore v1.2.0 — Зимний релиз `.
5. В поле описания можно вставить: `Стабильный релиз с поддержкой Windows .exe и автообновлением.`
6. Нажмите зелёную кнопку **Publish release** (Опубликовать релиз).

### Шаг 3: Скачать готовый .exe
1. После нажатия «Publish release» перейдите во вкладку **Actions** сверху репозитория.
2. Вы увидите запущенный процесс сборки релиза (`Build Windows EXE & Auto-Updater`).
3. Подождите 2–3 минуты, пока процесс завершится зелёной галочкой (✅).
4. Вернитесь на главную страницу репозитория или в раздел **Releases** — там появится готовый установщик `OptiCore-Setup-1.2.0.exe` и портативная версия `OptiCore-Portable-1.2.0.exe`, которые вы и ваш друг сможете скачать одним кликом!
